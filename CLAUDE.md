# HVML Parser for Node.js

An tool for consuming, editing, and producing [Hypervideo Markup Language](https://hypervideo.tech/) data, which is serializable as either XML or JSON. Takes design cues from the HTML and DOM specifications.

## Project Goals

- Consume as close to zero dependencies as possible.

## Commands

- `npm-minify` is our utility for publishing packages for public consumption; make sure it stays included in `package.json`.

## Conventions

- Task tracking is the Trello board "[HVML](https://trello.com/b/SJg4TLYz/hvml)". When closing a card, append a `**Commits**` section linking each hash to GitHub with plain link text — no backticks inside the link brackets (Trello's renderer drops the hyperlink around nested code spans).

- Commit messages explain the why.

- Writing style (naming, comments, terminal output) follows the maintainer's global conventions in `~/.claude/CLAUDE.md`.
